## A cockpit, not a file browser

AlphaFold published 214 million predicted protein structures and a file browser
to find them in. GenomeCanvas is a small cockpit instead: <Fact id="proteins" /> (proteins,
graph nodes and edges) float in a Three.js scene as alpha-carbon backbone ribbons coloured vertex by
vertex with AlphaFold's own confidence scores, linked to a knowledge graph of
diseases, drugs and trials. A double-click hands off to Mol*, the viewer
AlphaFold DB itself ships — side-loaded, so it costs
<Fact id="molstar-bundle" /> in the bundle.

## The interface moves before it speaks

Ask for the proteins involved in a disease and the backend streams typed UI
commands ahead of any prose: the universe dims, the graph re-roots and the
camera re-frames before the first sentence arrives. Every answer is built from
local data first and the model only re-words a result that is already correct,
so there are <Fact id="external-calls" /> at request time and the app works with
no API key at all.

## Honest about where it stands

The deployment is configured but not provisioned, so the code is the artifact
rather than a URL. The similarity measure ranks by backbone shape distance, not
fold similarity, and the layout is hand-curated rather than a projection —
distinctions worth keeping straight, because the shorter versions of both claims
would be wrong.
