## The attack is not at the door

Prompt injection is a confused-deputy problem. The agent's credentials stay
valid, so identity never fires: the system sees an authorised agent making an
authorised request, because that is exactly what it is. In a swarm the poison
then travels along delegation, from whichever agent read the hostile input to
whoever it hands work to.

## Assume the injection lands

CORDON inverts the usual bet. Instead of trying to catch the injection, it
assumes one will land and asks what the compromised agent can still touch. An
agent that reads from a channel marked untrusted is tainted. Credential requests
go through a broker that denies a tainted agent a sensitive secret
<Fact id="secrets-leaked" /> — the deny happens before the resolver runs, so the
secret is never fetched and never enters the model's context.

## Tracing the outbreak

When a tainted agent reaches for a sensitive outbound action, CORDON walks the
delegation graph back to patient zero, computes the exposed set, and revokes
credentials and freezes sandboxes across it in infection order, leaving
unaffected agents running <Fact id="cascade-1k" />. Every decision is appended
to an Ed25519-signed, SHA-256 hash-chained audit log.
